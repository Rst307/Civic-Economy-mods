# 出口锚定生产链证据

## 状态

已接受

## 决策

Civic 将可信 `Production Inventory Export Event` 的消费分配所指向的来源 `Facility Accounting Receipt` 作为生产链贡献证据。聚合时先按来源 Receipt 去重，再计算该 Receipt 对应的已接受生产观察；同一来源 Receipt 被拆成多次出口时只能形成一次贡献。缺失或无法解析来源 Receipt 时失败关闭，不估算贡献。

## 背景与权衡

单独按 Create 配方完成次数或出口次数汇总，会把同一批中间产品在分批出口时重复放大；仅依靠物品 ID 和时间窗口又无法证明库存来自哪个核算入口。现有出口事件已经持久化了消费分配和库存年龄批次，因此来源 Receipt 是当前最小且可审计的生产链锚点。

这个决定只解决同一来源 Receipt 的拆分出口去重，不臆测跨设施 `EXPORT` 的上下游运输关系。后者需要一个由真实适配器提供的目标核算接口与下一份 Receipt 的明确关联；在该事实存在前，系统宁可漏算，也不能把相似物品或时间邻近事件拼成一条链。

## 后果

- 出口拆分、重放和不同出口类型不会重复计算同一来源 Receipt。
- 来源 Receipt 缺失、被破坏或无法关联时，贡献保持为零并留下可诊断的缺失计数。
- 生产链跨设施归属、承运和消费角色仍未实现，生产/基础设施继续保持 `PAUSED_ANOMALY`。
