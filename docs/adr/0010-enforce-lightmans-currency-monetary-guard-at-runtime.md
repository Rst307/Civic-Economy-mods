# Enforce the Lightman's Currency monetary guard at runtime

Civic Economy keeps the operator-owned Lightman's Currency configuration files unchanged, but overrides the pinned runtime's dangerous option reads with conservation-safe values and also blocks the corresponding issuance methods. For LC `1.21-2.3.0.5`, native Coin Mint crafting, minting and melting, free entity and chest coins, coin-generating villager and wandering-trader changes, seasonal rewards and replacements, bank interest, `/lcbank give`, and vanilla `/give` of LC money are unavailable. The method-level barriers are authoritative even if LC reloads a configuration whose stored values enable those features.

Writing replacement values through LC's config API during mod construction was unsafe because LC can serialize before its registries are bound. Applying values from a reload listener also caused config writes and clientbound synchronization at times when no server connection existed, and it could corrupt serialized coin options. A runtime read overlay avoids mutating operator files, while method-level barriers prevent a missed read or reload path from violating monetary conservation. This decision intentionally couples the guard to exact LC classes and method descriptors; any LC version change is compatibility work that must fail closed until bytecode/source inspection, compilation, and real runtime GameTests revalidate every guarded path.
